# STM32G474 ADC 上位机

基于 PyQt5 与 PyQt-Fluent-Widgets 的上位机软件，通过 USB 虚拟串口接收 STM32G474 的 4 路 ADC 帧数据，实时绘制 A-Mode（折线图）与 M-Mode（瀑布图），并支持实时录制到 TXT 文件。

## 运行环境

- Python 3.12+
- PyQt5
- PyQt-Fluent-Widgets (`pip install PyQt-Fluent-Widgets`)
- pyqtgraph
- pyserial
- numpy

建议在 Conda 虚拟环境中安装依赖：

```powershell
pip install PyQt5 PyQt-Fluent-Widgets pyqtgraph pyserial numpy
```

## 程序结构

代码采用模块化设计，便于维护和扩展：

| 模块 | 职责 |
|------|------|
| `main.py` | 应用入口（薄包装） |
| `MainWindow.py` | 主窗口 UI、串口与录制控制、信号连接 |
| `SerialReader.py` | 串口读取线程（QThread），帧解析协调 |
| `Protocol.py` | 二进制协议解析、校验、常量定义（纯函数） |
| `PlotPanel.py` | A-Mode 与 M-Mode 绘图组件 |
| `RecordingService.py` | 实时 TXT 写盘服务 |
| `RecordingUtils.py` | 文件名/路径校验、目录创建等工具函数 |

## 使用说明

### 基础操作

1. 运行 `python main.py` 启动应用。
2. 点击"刷新串口"后，从下拉列表选择 STM32 虚拟串口。
3. 点击"开始接收"启动串口连接。
4. 实时显示 4 个通道的 A-Mode（当前采样波形）和 M-Mode（时间序列瀑布图）。
5. 点击"停止"可关闭串口连接。

### 录制功能

1. **选择录制目录**：点击"选择录制目录"弹出文件夹选择对话框，指定输出路径。
2. **输入文件名**：在文件名输入框输入文件名（不需要 `.txt` 扩展名，程序自动添加）。
3. **开始录制**：先连接串口（点"开始接收"），再点"开始录制"。
   - 已录制帧数计数会实时更新。
   - 数据每帧实时写入 TXT 文件（确保不会因程序崩溃而丢失已记录的数据）。
4. **停止录制**：点"停止录制"关闭文件。
   - 关闭窗口、停止串口连接时也会自动停止录制。
5. **查看输出**：生成的 TXT 文件可用任何文本编辑器打开。

### 录制文件格式

每帧数据占 4 行（对应 4 个通道）。格式如下：

```
F000000 CH1 val_1 val_2 val_3 ... val_n
F000000 CH2 val_1 val_2 val_3 ... val_n
F000000 CH3 val_1 val_2 val_3 ... val_n
F000000 CH4 val_1 val_2 val_3 ... val_n
F000001 CH1 val_1 val_2 val_3 ... val_n
...
```

- **F000000**：帧序号（本次录制会话内从 0 开始递增）
- **CH1~4**：对应的通道号
- **val_1, val_2, ...**：该通道的采样值，空格分隔，精度为 1 位小数

示例（3 个采样点的 1 帧）：
```
F000000 CH1 100.0 105.2 98.7
F000000 CH2 250.3 260.1 245.8
F000000 CH3 -50.0 -45.3 -55.2
F000000 CH4 1000.0 1010.5 990.2
```

## 二进制协议格式

下位机 STM32 遵循的串口协议结构：

```
[帧头(2B)][长度(2B)][类型(1B)][数据(payload_len)][校验(2B)][帧尾(2B)]
├─ 帧头: 0xAA55 (固定)
├─ 长度: 小端序，范围 8~16384，必须是 8 的倍数
├─ 类型: 0x01 (ADC 数据)
├─ 数据: 4 通道交错的 int16（小端序）
├─ 校验: XOR 校验（从长度字段到数据末尾）
└─ 帧尾: 0x0D0A (固定)
```

采样点数自动从长度字段推导：`num_samples = payload_len / 8`

## 故障排查

| 问题 | 解决 |
|------|------|
| 无法打开串口 | 检查 STM32 驱动是否安装，确认 COM 端口号 |
| 接收到"校验和错误" | 检查下位机的校验算法是否一致 |
| 无法开始录制 | 确认已选择输出目录且文件名非空 |
| 文件名包含特殊字符错误 | 避免 Windows 非法字符：`< > : " / \ \| ? *` |
| 录制中丢帧 | 属于正常现象（高采样率）；已写入文件的数据不会丢失 |
